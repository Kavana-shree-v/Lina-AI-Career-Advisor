# 🤖 AI Career Guidance Chatbot

## 🚀 Project Overview
The **AI Career Guidance Chatbot** is an AI-powered chatbot developed using **Jotform AI Agent Builder**. It helps students discover suitable career paths based on their interests, strengths, and goals through an interactive conversational interface.

## 🎯 Problem Statement
Many students face confusion when choosing a career due to a lack of proper guidance, awareness, and clarity about different career opportunities.

This chatbot aims to simplify career decision-making by providing personalized career recommendations, required skills, and beginner-friendly learning roadmaps.

## ✨ Features
- 💬 Interactive chatbot interface
- 📞 Voice call interaction support
- 🧠 AI-based personalized career suggestions
- 🎯 Interest-based career recommendations
- 📚 Required skills for each career
- 🛣️ Beginner-friendly learning roadmaps
- 🤝 Simple and user-friendly guidance

## ⚙️ How It Works
1. The chatbot asks users about their interests, strengths, and career preferences.
2. It analyzes the user's responses using AI-based conversational logic.
3. It suggests 2–3 suitable career paths based on the responses.
4. It provides relevant information, including:
   - Required technical and soft skills
   - Beginner-friendly learning roadmaps
   - Guidance to help users choose the right career direction.

## 🛠️ Tech Stack
- **Platform:** Jotform AI Agent Builder
- **Technology:** AI-based conversational logic
- **Development Approach:** No-code AI development platform
